# 사락 디자인 셋 · 빛이 물든 한 장

- `사락-디자인셋.html`: 색, 글자, 부품, 네 기기 화면 전체. `fonts`, `icon` 폴더와 함께 두고 엽니다.
- `previews`: 화면별 그림
- SwiftUI 코드의 원본은 `ios-native/Sarak/Core/SarakDesign.swift`입니다.
- `tokens.json`: 색과 크기 값
- `icon`: 앱 아이콘 제안(기본·다크·틴트, SVG와 1024px)
- `source`: HTML을 다시 만드는 파일. 저장소의 bible.db를 씁니다.

## 지킬 것
1. 한 화면에 큰 파스텔 면은 하나. 들린 종이 아래로만 다음 시간의 색이 보입니다.
2. 말씀이 화면에서 가장 큽니다. 줄임표로 자르지 않습니다.
3. 진한 갈색 면은 주 버튼과 켜진 스위치에만 씁니다.
4. 읽기 화면에는 종이 면을 깔지 않습니다.
5. 그라데이션, 카드 안의 카드, 연속 기록, 순위를 쓰지 않습니다.
6. 탭과 아이콘은 시스템 TabView와 SF Symbols를 씁니다. 시안의 아이콘은 자리 표시입니다.
7. Duo는 닫힘과 펼침 가로에서 오른쪽 시스템 띠가 안전 영역입니다. 종이는 그 아래까지, 글은 안전 영역 안까지.

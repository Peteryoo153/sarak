# 사락 3.0 전체 디자인 시스템과 화면 세트

아래 조건으로 iOS 앱 "사락"의 디자인 시스템, 로고, 일러스트, 앱 화면, 알림, 위젯, 애플워치, iPhone Duo 화면을 만들어 주세요. 모든 문구는 한국어입니다. 한 번에 다 만들지 말고 맨 아래 "작업 순서"대로 진행하고, 단계마다 멈추어 확인을 받으세요.

## 1. 앱의 정체성
- 이름: 사락 (책장이 사락 넘어가는 소리)
- 한 문장: "하루 네 번 말씀이 찾아오고, 하루 5분이면 1년에 신약을 읽습니다."
- 공간: 골방. 문을 닫고 조용히 말씀을 읽는 작고 따뜻한 방
- 사용자: 바쁜 한국의 그리스도인. 앱을 열지 않아도 알림으로 말씀을 만납니다.
- 주인공: 앱 화면보다 **찾아오는 말씀 알림**
- 느낌: 미니멀, 따뜻함, 포근함, 조용한 기쁨. 다시 들어오고 싶은 방
- 피할 것: 순위, 경쟁, 불꽃 연속 기록, 밀린 일수, 죄책감을 주는 문구, 장식용 그라데이션, 유리 효과 남용, 과한 그림자, 카드 안의 카드

## 2. 레퍼런스 사용법 (첨부 이미지)
- **Prayer app design (Figma, yugandhar):** 인사말, 큰 주인공 이미지, 가로 목록, 간결한 상세 화면과 두 개의 버튼이라는 깔끔한 정보 구조만 참고합니다. 파란 그라데이션, 화면 배치, 사진, 아이콘, 콘텐츠는 복제하지 않습니다.
- **인물 일러스트:** 평면 색, 짧고 가는 갈색 선, 여유로운 옷 주름, 생기 있는 몸짓이라는 분위기만 참고합니다. 같은 인물, 포즈, 옷을 쓰지 말고 새로 그립니다.
- **색상 이미지 5장:** 아래 다섯 테마의 원천입니다.

## 4. 글꼴과 형태
- 말씀: Gowun Batang. 홈 28, 읽기 19(사용자 조절 14~28), 행간 1.65
- 화면 글자: iOS 시스템 글꼴. 제목 22, 본문 17, 보조 15, 최소 12
- Dynamic Type 최대 크기에서도 말씀이 잘리지 않아야 합니다. 한국어는 어절 단위로 줄바꿈합니다.
- 간격 4/8/12/16/24/32/48, 좌우 여백 24, 모서리 12와 24 두 가지, 터치 영역 최소 44pt
- 아이콘: SF Symbols 우선. 새 아이콘이 필요하면 둥근 끝, 1.75pt 선
- 움직임: 책장이 넘어가듯 250~400ms, '동작 줄이기'에서는 부드러운 나타남으로 대체

## 5. 로고와 앱 아이콘
현재 로고와 달라도 됩니다. 서로 확실히 다른 세 안을 만드세요.
- A **불 켜진 창:** 열린 책의 두 쪽이 작은 창이 되고 안에 빛이 있음
- B **넘어가는 한 장:** 한 획으로 그린 책장, 빈 공간에서 한글 'ㅅ'이 보임
- C **살짝 열린 문:** 골방 문틈의 빛이 펼친 책 모양이 됨

각 안: 심볼, '사락' 워드마크, 가로 조합, 단색, 24px 테스트, 1024px 앱 아이콘(기본/다크/틴트). 앱 아이콘은 글자 없이, 모서리를 미리 깎지 않습니다. 벡터로 만듭니다. 세 안을 비교하고 하나를 추천하되 제가 고를 때까지 나머지 화면에 확정하지 마세요. 흔한 십자가+책 조합은 피합니다.

## 6. 일러스트
평면 면, 테마의 장식 색 2~3개, 가는 짙은 선. 다양한 연령의 한국인 중심 공동체. 얼굴은 단순하고 다정하게, 손가락 수와 팔다리는 정확하게. 예수님과 하나님은 얼굴로 그리지 않습니다. 벡터, 투명 배경.

1. 첫 만남: 창가 의자에서 휴대폰의 말씀을 보는 사람
2. 아침: 커튼을 여는 사람
3. 한낮: 지하철에서 잠시 멈춘 사람
4. 쉼: 찻잔을 든 손
5. 밤: 이불 옆 작은 등불과 책
6. 다시 옴: 책갈피가 꽂힌 채 기다리는 책
7. 빈 말씀첩: 비어 있는 작은 책장
8. 완독: 세 사람이 책을 둘러싸고 기뻐함 (첨부 일러스트의 활기를 조용하게)
9. 함께: 저녁 건물의 불 켜진 창들
10. 알림 꺼짐: 닫힌 창과 쪽지

말씀 본문 화면에는 일러스트를 넣지 않습니다. 홈은 작게 한 점만 씁니다.

## 7. iPhone 화면 (402×874pt, 라이트 기본 + 핵심 화면 다크)
탭 세 개: **골방 · 성경 · 말씀첩**. 설정은 골방 오른쪽 위.

**01 첫 실행** "하루 네 번, 말씀이 사락 찾아갑니다." / 아침·한낮·쉼·밤 / 버튼 [말씀 받기] / "시간은 언제든 바꿀 수 있어요". 로그인과 질문 없음. 다음은 시스템 알림 허용 창. 거절 상태도 그립니다.

**02 골방 (아침·한낮·해 질 녘·밤 네 상태)** 날짜, 짧은 인사, 작은 그림, 큰 말씀, 출처, 한 개의 주 버튼 [오늘의 본문 5분쯤 읽기], 보조 문구 "하루 5분, 25일이면 마가복음 한 권." 화면 첫눈에 말씀이 먼저 보입니다. 빛의 변화는 배경 농도와 그림으로만 은은하게.

**03 읽기** "마가복음 4:30–5:20". 절 번호는 작게, 이어 읽기. 긴 본문 스크롤, 글자 크기, 듣기. 구절 선택 시 [품기] [복사] [한 줄 남기기]. 끝에서 [오늘 본문 마치기]. 10분 사용자는 이어서 "구약 이야기 5분 더" 선택.

**04 읽기를 마침** "오늘 5분, 마가복음이 사락 한 장 더 넘어갔어요." 선택형 감사/묵상 한 줄. [함께 나누기]는 보조.

**05 성경** 이어 읽기, 구약/신약, 책과 장, 검색.

**06 말씀첩** 품은 말씀, 남긴 한 줄, 받은 말씀, 달력. 빈 상태 포함.

**07 완독** "마가복음 한 권을 다 읽었어요. 하루 5분이 여기까지 데려왔네요. 다음은 시편에서 잠시 쉬어가요."

**08 다시 옴** "책갈피는 그 자리에 있어요. 오늘 5분부터 다시 펼쳐요."

**09 함께** 골방에서 들어가는 작은 화면. 불 켜진 창, 그룹 통독, 말씀 보내기. 순위 없음. 불빛 공개 켜고 끄기. 신고와 숨기기 포함.

**10 알림 설정** 전체 켬/끔, 오늘 하루 쉬기, 네 시간의 개별 켬/끔, 시간 추가, 요일, 소리, 잠금화면에 말씀 보이기, 미리 받아보기, 기본값 되돌리기. 기본: 아침을 여는 말씀 오전 7:00(사락 소리) · 한낮의 말씀 오후 12:20(무음) · 쉼의 말씀 오후 4:00(무음) · 하루를 덮는 말씀 밤 9:30(무음). iPhone 설정에서 막힌 상태와 [아이폰 설정 열기]도 그립니다.

**11 설정** 읽기 시간 5분/10분, 테마, 글자, 알림, 역본, 로그인과 동기화, 그룹, 문의, 계정 삭제.

**12 상태** 로딩, 오프라인, 저장 실패와 다시 시도.

## 8. 알림 (가장 중요한 화면)
실제 iOS가 그리는 영역을 바꾸지 마세요. 기본 알림의 배경과 글꼴은 시스템이 정합니다. 커스텀은 앱 아이콘, 첨부 이미지, 소리, **길게 눌렀을 때 펼친 화면**에서만 합니다.

- 잠금화면 기본 알림 4종: 제목은 말씀의 자리, 본문은 구절과 출처. 60자 이내
- 내용 숨김: "말씀이 찾아왔어요"
- 펼친 알림: 테마 배경, 큰 명조 말씀, 출처, 작은 시간대 그림. 동작은 시스템 버튼으로 [마음에 품기] [아멘] [한 줄 남기기] [한 시간 뒤]
- 여러 개가 묶인 상태, 친구가 보낸 말씀, 다크 모드
- 알림 문구: 말씀 또는 "오늘의 본문은 5분이면 충분해요". 재촉하지 않습니다.

예시 말씀 (글자를 바꾸지 말 것):
아침 "겨자씨 한 알과 같으니" 막 4:31 · 한낮 "심긴 후에는 자라서 모든 풀보다 커지며" 막 4:32 · 쉼 "안심하라 내니 두려워하지 말라" 막 6:50 · 밤 "잠잠하라 고요하라 하시니 바람이 그치고 아주 잔잔하여지더라" 막 4:39

## 9. 위젯
- 홈: 소형(말씀+출처), 중형(말씀+오늘 본문), 대형(말씀+작은 골방+읽기 버튼+말씀의 흐름 4점)
- 잠금화면: 원형(불 켜진 창, 오늘 읽음 여부), 사각형(짧은 말씀), 인라인(출처)
- 스탠바이: 멀리서 보이는 말씀, 밤의 빨간 단색 모드
- 각 위젯의 전체 색상, 틴트, 투명 모드. 긴 말씀, 짧은 말씀, 읽음 상태
- 작은 위젯에서 말씀을 중간에 자르지 말고 더 짧은 감수 구절을 사용합니다.

## 10. 애플워치
41/42mm, 45/46mm, 49mm 크기 기준. 어두운 바탕, 큰 글자.
- 짧게 보는 알림: 아이콘과 "사락 · 쉼의 말씀"
- 길게 보는 알림: 말씀, 출처, [품기] [아멘] [나중에]
- 앱: 오늘의 말씀 한 화면, 다음 말씀 시간
- 컴플리케이션: 원형, 직사각형, 모서리, 인라인 / 스마트 스택 위젯
- 항상 표시 상태, 내용 숨김, 긴 구절의 크라운 스크롤
- 워치에서 긴 성경 읽기나 자판 입력은 만들지 않습니다.

## 11. iPhone Duo와 iPad
iPhone Duo 시뮬레이터 화면 기준: **외부 466×678pt, 내부 669×951pt (세로)**. 가로도 그립니다.
- 닫힘: 높이가 짧으므로 말씀과 버튼이 한 화면에 들어오게. 그림을 먼저 줄입니다.
- 펼침 세로: 본문 폭을 560pt 이하로 두고 넓은 여백
- 펼침 가로: **펼친 책.** 왼쪽은 오늘의 말씀이나 차례, 오른쪽은 본문과 여백 메모
- 반쯤 접힘: 위는 말씀, 아래는 읽기·듣기 조작. 접히는 부분에 글자나 버튼을 두지 않습니다.
- 접고 펼 때 읽던 절, 선택, 메모 입력이 이어집니다.
- 필수 화면: 골방, 읽기, 말씀첩, 알림 설정. 기기 이름이나 고정 크기가 아니라 가용 폭에 반응하는 규칙을 적습니다.
- iPad 세로·가로와 화면 분할에서도 같은 규칙을 씁니다.

## 12. 접근성 완료 기준
대비 4.5:1 이상, VoiceOver 읽는 순서, 큰 글자, 투명도 줄이기, 동작 줄이기, 색만으로 상태를 구분하지 않기. 말씀 텍스트를 이미지로 만들지 않기.

## 13. 결과물
1. 색/글꼴/간격 토큰표 (SwiftUI로 옮길 수 있는 이름과 값, 다섯 테마 라이트/다크)
2. 버튼, 말씀 블록, 목록 행, 시간 행, 토글, 시트, 빈 상태 등 컴포넌트와 상태
3. 위 모든 화면과 연결되는 프로토타입: 알림 → 펼침 → 읽기 → 마침 → 말씀첩
4. 로고 3안, 일러스트 10점, 앱 아이콘
5. 화면마다 짧은 설계 이유와 구현 메모

2. **시스템:** 선택된 로고와 방향으로 토큰, 컴포넌트, 다섯 테마
3. **iPhone:** 전체 화면과 상태
4. **바깥 화면:** 알림, 위젯, 애플워치
5. **큰 화면:** iPhone Duo, iPad
6. **점검:** 대비, 큰 글자, 넘침, 화면 간 일관성을 확인하고 고친 목록 제출
